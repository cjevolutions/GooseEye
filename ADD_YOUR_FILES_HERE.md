# Optional files before publish

Drop any extra assets in this repo before the initial GitHub push, for example:

- `LICENSE`
- `docs/images/mosfet-module.jpg`
- `docs/images/wiring-photos.jpg`
- Fuse / 12 V tap part numbers

Then commit from `gooseeye-hardware/`:

```bash
git add -A && git commit -m "Add project assets"
```

If you already pushed, add files in a follow-up commit.
